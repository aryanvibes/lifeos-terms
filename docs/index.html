Core Policy

This Privacy Policy applies to the LifeOS mobile application for Android (Package: com.aistudio.lifeos.app) and this official Trust Center. LifeOS is engineered with a **Local-First Architecture**, ensuring that personal task scheduling, relationship management, and financial ledgers stay on your device hardware.

A. Information Stored on Your Smartphone (Local Room SQLite)

  • Tasks & Routines: Task descriptions, target timestamps, completion state, priority tags, and reminder preferences.

  • Financial Ledgers & Invoices: Transaction amounts, GST/tax markers, timestamps, category tags, and invoice records.

B. Information Stored on Cloud Infrastructure

🤖 4. Gemini AI Terms & Disclaimers

AI Disclosures

LifeOS incorporates artificial intelligence powered by Google Gemini API and client-side deterministic tool routing.

How LifeOS AI Works:
1. Local Query Evaluation: When you enter an AI query, LifeOS first tests whether the request can be resolved using local mathematical, formatting, or deterministic tools on your device.
2. Ephemeral Transmission: If external AI processing is necessary, only the specific prompt text is transmitted over TLS 1.3 to Google Gemini API servers. Your SQLite database is never uploaded.
3. Zero Model Training: Your private workspace notes and personal records are not used to train public machine learning models.

🔒 8. Security & Data Protection Architecture

Security Posture

LifeOS implements multi-layered security controls to protect your data both at rest and in transit:

  • Transit Encryption: All communications between the LifeOS application, Firebase Authentication, and the Gemini API are encrypted using TLS 1.3 with standard certificate validation.
  • Storage Sandboxing: The Room SQLite database is maintained strictly within Android's private internal storage directory (/data/data/com.aistudio.lifeos.app/), inaccessible to other apps on non-rooted devices.
  • FLAG_SECURE Screen Shielding: When app lock is active, LifeOS engages FLAG_SECURE to prevent Android's recent apps switcher from taking screenshots of your financial ledgers and sensitive tasks.
  • Biometric Security: Authentication is handled through Android's system BiometricPrompt, ensuring cryptographic operations occur within the device's secure hardware enclave.
